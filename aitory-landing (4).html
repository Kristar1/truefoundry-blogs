FAQ

Questions platform & security teams ask.

Which coding agents does AITori govern?

Claude Code, Cursor, GitHub Copilot and Codex out of the box — plus any custom or MCP-connected agent, auto-detected on its first request. Coverage is behavioral, not tied to an approved app list.

Do I have to install something on every developer's machine?

No. AITori is gateway-native and governs coding-agent traffic at the TrueFoundry AI Gateway and MCP Gateway — nothing to roll out per device, and no IDE changes.

Where does my data go?

AITori runs inside your AWS, GCP or Azure account, on-prem, or air-gapped. Prompts, code context, audit logs and policy decisions stay within your boundary. SOC 2 Type II, HIPAA and ITAR ready.

How does AITori detect shadow AI?

Because it governs at the traffic layer, AITori surfaces every agent that reaches a model or tool — including ones security never reviewed — with the developer, destination, and data flowing outbound.

What does it do to latency?

AITori adds roughly 3–4 ms at the gateway and handles 350+ requests per second on a single vCPU, scaling horizontally. Developers feel nothing; security sees everything.
